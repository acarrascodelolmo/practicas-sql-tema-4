# Tema 4 · Prácticas de SQL

[Resumen de uso de IA · SQL-T4-4827](uso-ia.txt)

Scripts para SQLite. Se pueden ejecutar desde la pestaña «Ejecutar SQL» de DB Browser for SQLite.

- **Práctica 1.** Crea una base vacía, abre `practica_1.sql` y ejecútalo una vez. Para comprobar las cinco altas, ejecuta `SELECT * FROM ParaiZooHuesped;`.
- **Práctica 2.** Descomprime el archivo de clase `bbdd.zip`, abre `moviebig.db` y ejecuta cada consulta numerada de `practica_2.sql` por separado. El campo `revenue` representa la recaudación. Las búsquedas con `LIKE` admiten coincidencias parciales, como «aliens».
- **Práctica 3.** Abre `moviebig.db` y ejecuta las seis consultas de `practica_3.sql` por separado. El ejercicio 3 devuelve cero filas porque los datos de clase solo indican el día de estreno. El ejercicio 6 utiliza las funciones JSON de SQLite para leer los nombres de las productoras.
